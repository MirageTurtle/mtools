# mtools

Maybe, mtools means **M**irage**T**urtle's t**ools**.

| Directory | Description |
| --- | --- |
| [`bash`](./bash) | Shell scripts for notifications, cleanup, tunnels, Kafka checks, and small macOS utilities. |
| [`python`](./python) | Python scripts for OSS, DNS, network checks, and config conversion. |
| [`tampermonkey`](./tampermonkey) | Tampermonkey scripts for common website tweaks. |
| [`vba`](./vba) | VBA macro for PowerPoint slide number fixes. |
