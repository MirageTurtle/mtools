# Bash

Some shell scripts for daily use.

| Script | Description |
| --- | --- |
| [`bark_send.sh`](./bark_send.sh) | Send Bark notifications with `BARK_KEY`. |
| [`tg_bot_send.sh`](./tg_bot_send.sh) | Send Telegram bot messages with `TELEGRAM_BOT_TOKEN`. |
| [`clean_tmp.sh`](./clean_tmp.sh) | Clean old top-level entries in `~/tmp`. |
| [`sync_missing_files.sh`](./sync_missing_files.sh) | Copy files that exist in a reference directory but are missing in another directory. |
| [`ssh_tunnel.sh`](./ssh_tunnel.sh) | Keep a reverse SSH tunnel alive. |
| [`kafka_consume_speedtest.sh`](./kafka_consume_speedtest.sh) | Print Kafka consumer group lag every second. |
| [`macos_check_power.sh`](./macos_check_power.sh) | Notify when a Mac switches between battery and power adapter. |
| [`wait_for_it.sh`](./wait_for_it.sh) | Run a command after selected PIDs exit or after a timer elapses. |
| [`reset_navicat.sh`](./reset_navicat.sh) | Reset Navicat trial state. |
