# Python

Some tools written in Python.

| Script | Description |
| --- | --- |
| [`oss.py`](./oss.py) | Upload/download files or directories with JDCLOUD OSS. |
| [`dns_query.py`](./dns_query.py) | Query DNS records from one domain or a file, with optional CNAME recursion. |
| [`crack_dns_hex.py`](./crack_dns_hex.py) | Decode DNS packet hex, using Scapy when available. |
| [`ip_net_check.py`](./ip_net_check.py) | Check whether an IP belongs to a CIDR network. |
| [`vmess_to_singbox.py`](./vmess_to_singbox.py) | Convert a `vmess://` URL to sing-box outbound JSON. |
| [`env_test.py`](./env_test.py) | Print Python, OS, PyTorch, and CUDA environment info. |
