# Tampermonkey Scripts

Some Tampermonkey scripts for daily use.

| Script | Website | Description |
| --- | --- | --- |
| [`bulk_delete_chatgpt.js`](./bulk_delete_chatgpt.js) | ChatGPT | Add bulk selection and deletion for ChatGPT conversations, with Shift range selection. |
| [`gsearch_lang.js`](./gsearch_lang.js) | Google Search | Add a language filter to quickly switch between all languages, Chinese, and English. |
| [`github_unstar_all.js`](./github_unstar_all.js) | GitHub Stars | Add a button to unstar all repositories on the current stars page. |
| [`notion_chinese_brackets.js`](./notion_chinese_brackets.js) | Notion | Convert `【】` to `[]` for easier Notion checkbox input with Chinese IMEs. |
| [`canva.js`](./canva.js) | Canva | Find matching Canva image resources and open them in new tabs. |
| [`wordreference_chinese_link.js`](./wordreference_chinese_link.js) | WordReference | Add a Chinese definition link to English definition pages. |
| [`kmf_translation.js`](./kmf_translation.js) | KMF TOEFL | Add a global show/hide translations button on listening practice pages. |
| [`ustc_mail.js`](./ustc_mail.js) | USTC Mail | Split and correct `@ustc.edu.cn` / `@mail.ustc.edu.cn` domains on the login page. |
| [`auto_select_consular_port.js`](./auto_select_consular_port.js) | US Visa Scheduling | Add a button to auto-select the only available consular post option. |
| [`notify_me_when_in_room.js`](./notify_me_when_in_room.js) | US Visa Scheduling | Send a Bark notification after leaving the Cloudflare waiting room. |
| [`visa_api_monitor.js`](./visa_api_monitor.js) | US Visa Scheduling | Monitor schedule API responses and show a toast when earlier slots are found. |
